# 📝 Todo Manager

A modern full-stack Todo Management application built using **React** and **Node.js (Express)** as part of the ZipTrrip selection assignment.

The application allows users to create, manage, search, update, and organize their daily tasks through a clean and responsive interface.

---

## Features

* Create new todos
* View all todos
* View individual todo details
* Update existing todos
* Delete todos
* Mark todos as Completed/Pending
* Search todos by title
* Priority badges (High / Medium / Low)
* Status badges (Completed / Pending)
* Todo statistics
* Responsive UI
* Multi-page React application
* RESTful Express APIs
* JSON file-based data storage
