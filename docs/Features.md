# Features

## 1. Create Todo

Users can create a new todo by entering:

* Title
* Description
* Priority

---

## 2. View Todos

Displays all todos as responsive cards.

Each card contains:

* Title
* Description
* Priority
* Status
* Action Buttons

---

## 3. Todo Details

Clicking **View** opens a dedicated page showing complete information about a selected todo.

Uses query parameters:

```
/todo?id=<todo-id>
```

---

## 4. Edit Todo

Selecting **Edit** automatically populates the form.

After updating, the changes are immediately reflected.

---

## 5. Delete Todo

Todos can be deleted after user confirmation.

---

## 6. Toggle Status

Users can instantly switch between:

* Pending
* Completed

without opening the edit form.

---

## 7. Search

Real-time search filters todos based on the title.

---

## 8. Statistics

Displays:

* Total Todos
* Completed Todos
* Pending Todos

---

## 9. Priority Badges

Visual indicators:

* 🔴 High
* 🟡 Medium
* 🟢 Low

---

## 10. Status Badges

Visual indicators:

* 🟢 Completed
* 🟡 Pending

---

## 11. Responsive Design

The application adapts to different screen sizes for improved usability.
